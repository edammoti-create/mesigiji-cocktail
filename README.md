# MeshiGiji Cocktail

GitHub Pages向けの静的サイトです。About、開催日時、Character、Informationの独立ページで構成しています。Characterページには、トム（Tom and Jerry）、パラディエル（Paradise）、アレク（Alexander）、カメリア（Hot Campari）を掲載しています。

## 公開

GitHubリポジトリ `edammoti-create/mesigiji-cocktail` の **Settings → Pages → Deploy from a branch → main / root** を選ぶと公開できます。公開URLは `https://edammoti-create.github.io/mesigiji-cocktail/` です。

## ファイル

- `index.html` ページ構造
- `schedule.html` 開催日時
- `character.html` キャラクター紹介
- `information.html` 参加方法など
- `collection.html` Collectionページ（内容準備中）
- `style.css` 配色・レイアウト・レスポンシブ表示
- `script.js` モバイルメニュー
- `assets/` キャラクター画像
